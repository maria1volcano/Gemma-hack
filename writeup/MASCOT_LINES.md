# Mascot lines (kid voice)

## Warn
- "Hold on — this page is trying to rush you. Let's slow down."
- "That looks clickbaity. Want a safer site instead?"

## Block / phishing
- "Stop! Real games never ask for your password like this. Close it and tell a grown-up."
- "This page is pretending to be something safe. I blocked it for you."

## Highlight
- "Tap the button I'm pointing at — that's the safe next step."
- "See the glowing ring? That's the control we care about."

## Success / allow
- "This page looks fine. You've got this!"
- "Nice — this is a good place to keep learning."

## Parent summaries (one line)
- "Warned on clickbait / giveaway-style page."
- "Blocked phishing-style login asking for a password."
- "Kid asked coach for help opening Classroom."
